## The Open Project Series

I'm building a series of open-source tools for everyday work. Starting with Markdown writing and resume building, I want to make useful software you can run, understand, and make your own.

我正在做一系列 **open 项目计划**：从日常会用到的工具出发，把想法做成可以运行、修改和继续改造的开源软件。下面是这个系列的起点，后续会持续扩展。

| Project | What it does | Try it |
| --- | --- | --- |
| **[Open&nbsp;Typora](https://github.com/AniChikage/open-typora)** | Local-first Markdown editing. Write directly in the rendered page and keep your own `.md` files. | [Download](https://github.com/AniChikage/open-typora/releases/latest) · [Demo](https://open-typora.comicyueyu.chatgpt.site) |
| **[Open&nbsp;Resume](https://github.com/AniChikage/open-resume)** | Self-hosted resume builder. All templates, unlimited resumes, and free exports without watermarks. | [Self-host](https://github.com/AniChikage/open-resume#getting-started) · [Walkthrough](https://github.com/AniChikage/open-resume#demo) |

<sub>Open Typora is an independent, unofficial project, unaffiliated with Typora.</sub>

**More open projects are on the way.** I'll keep improving these tools while exploring what to build next.
