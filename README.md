## The Open Project Series

I'm building a series of open-source tools for everyday work — starting with Markdown writing and resume building, with more projects to come.

The idea is simple: take a tool I'd use myself, make it useful, and share the code so others can run it, learn from it, and make it their own.

我正在做一系列 **open 项目计划**：从日常会用到的工具出发，逐个做成可以运行、修改和继续改造的开源软件。目前从 Markdown 写作和简历制作开始，后续会持续扩展。

### What I'm aiming for

- **Useful in daily life** — start with a real task and a working tool.
- **Control over your data** — favor local files, portable formats, and self-hosting where they fit.
- **Room to make it yours** — share the source, document how to run it, and improve it through feedback.

### What's next?

I'll keep improving these projects and adding new tools to the series.
